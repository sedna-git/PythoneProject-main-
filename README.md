 🛒 Online Store Management System

A Python-based Online Store Management System designed to manage customers, products, and orders through a simple and organized interface.

  About The Project

This project is a store management application developed with Python. It provides a centralized menu that allows users to manage different sections of an online store, including customer management, product management, and order management.

The system also provides reporting and export functionality, allowing users to generate reports about customers, products, and orders.

  Features

- **Customer Management**
  - Add new customers
  - View customer information
  - Manage customer records

- **Product Management**
  - Add new products
  - View product information
  - Manage product records

- **Order Management**
  - Manage customer orders
  - View order information

- **Main Menu**
  - Centralized management through a main menu
  - Easy navigation between different sections

- **Reports & Export**
  - Generate customer reports
  - Generate product reports
  - Generate order reports
  - Export reports for further use
